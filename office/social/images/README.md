# Pictures for posts

Drop pictures here (jpg, png or webp). Only pictures you own or may use. A picture showing another brand's logo or someone else's work needs a rights check.

Names the matcher (`python scripts/social_images.py`) understands:
- `<yyyy-mm-dd>-morning.jpg` or `-evening.jpg`: for that day's post.
- `<slug>-<topic>.jpg`: a library picture for a shoe, where `<slug>` is the `slug:` line of its file in `office/social/facts/` (for example `nike-dunk-low-midsole.jpg`, `adidas-samba-tag.jpg`). It is used for any day that shoe is picked.
Each day's draft file has a Pictures section saying what is still missing.
