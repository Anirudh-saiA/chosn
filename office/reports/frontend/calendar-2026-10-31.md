# Releases > Drops calendar: India first, released elsewhere, premium redo (2026-10-31)

Branch `team/calendar` (worktree). Not pushed.

## What changed
- `apps/web/src/lib/drop-region.ts` (new, pure): `isIndiaDrop`, `countryOf`, `officialLinks`, `sourceLink`. Official-domain allowlist (brand sites, SNKRS via nike.com, Comet, Gully Labs, a few named retailers). Only https, no credentials, host must match (look-alike hosts rejected). A tracker or news site is never a buy button.
- `DropsExplorer.tsx` rewritten: tabs **India** (default) and **Released elsewhere**; Month / Week / List switch; brand dropdown (SelectMenu) and, on Elsewhere, a country dropdown.
- `ReleaseCalendar.tsx` (new): month grid (dots for 1-3 releases, count for more, today ringed amber, picked day black), tap a day and its releases open in a rounded sheet below (no day picked = whole month); week view (7 blocks); list view with sticky month headings and "Show earlier releases". Sticky bar with Previous / Next / Today. Roving-tabindex keyboard: arrows, Home/End, PageUp/PageDown, Enter. 44px targets. "Today" is computed in IST so server and browser agree. Clear empty states with a jump button.
- `ReleaseRow.tsx` (new): picture, brand, model, time, rupee price, Confirmed/Reported/Unconfirmed badge, India tag or country chip (code + name), source line ("Reported by X", marked as a source). Elsewhere rows show **Buy at official site** (new tab, `rel="noopener noreferrer"`, retailer and host under it) only when an official link exists; otherwise the text "No official store link on file yet" and no button.
- API (additive only): the drops list now also returns `purchaseLinks` (`drops.service.ts`). No schema change, no restart.
- Page intro line updated (no longer says US drops are in dollars).
- Tests: `apps/api/src/drops/drop-region.spec.ts` (imports the web lib). API vitest 250/250, web tsc and eslint (max-warnings 0), api tsc all clean.

## Data gaps found (real data, 175 drops)
- **No country field.** Only `regions` tags: us (164), global, india. Country is derived from the tag; "global" shows "Worldwide (country not stated)".
- **Zero non-India drops have a purchase link.** Only 3 drops hold any (Comet vault, two Nike India pages). 164 US drops have just a tracker source (SneakerFiles / SoleDispatch), which is a source, not a shop. So today the Elsewhere tab shows no Buy buttons. The desk needs to fill `purchase_links` (brand launch page, SNKRS) for these, or add a country column.
- 13 drops tagged "us" are flagged `in_indian_stores`; I count them as India (labelled "In Indian stores") because otherwise India holds only 9 drops, all past. Decision for the founder; one-line change in `isIndiaDrop`. India has no upcoming release as of 31 Oct besides these.
- Earlier months were previously hidden; the calendar now allows going back to the earliest release.
