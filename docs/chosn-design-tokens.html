CHOSN Design Tokens

CHOSN reads as a trading terminal for sneakers, not a storefront: a dark data surface for price comparison, a light editorial surface for news, one reserved signal color for buy/positive movement, and every price treated as the most important thing on its page. Locked below, ready for a Tailwind config and a motion implementation tomorrow.

Section 01

Color

Two surfaces, not one: Vault for anywhere prices and market data live, Chalk for anywhere CHOSN is writing, not comparing. One accent — Signal — is spent exclusively on buy/positive movement. It never decorates a button, a logo, or a nav item.

Vault

#0F1613

Primary dark surface — price comparison, market intelligence, terminal UI.

Chalk

#EFF1EA

Primary light surface — news, landing copy sections, editorial pages.

Moss

#6B7268

Neutral gray-green ramp — hairline borders, dividers, secondary text on both surfaces.

Signal

#22CC85

Reserved: buy signals, positive trend deltas, verified badges. Earned, not decorative.

Brass

#C6963C

Brand mark only — wordmark, section dividers, SKU tag chips. Never semantic.

Rust

#C4643B

Reserved: wait signals, negative trend deltas. Pairs with Signal, never appears alone as brand color.

Deliberately not Warm cream + terracotta, and near-black + a single neon pop, are the two defaults every AI-generated startup page reaches for. Vault carries a green undertone tied specifically to authentication and market-signal meaning, not decoration — and the color that actually identifies CHOSN as a brand is Brass, not Signal. A generic "green fintech app" spends green on its logo; CHOSN doesn't.

The list column carries no images on purpose: it reads like a ticker for stories, matching the terminal's own information density.

Section 04

Principles

Four rules that hold for every screen built after today, not just the three in the brief.

01

Numbers outrank the sentence around them. Any price, percentage, SKU, or timestamp sets in JetBrains Mono at a weight and size that reads as the important thing on the line, even mid-paragraph.

02

Zero radius, hairline border, no shadow — ever. Depth comes from Vault vs Vault-raised surface contrast, never from a drop shadow. One language, no exceptions, including on chips and buttons.

03

Motion is the ticker, or it's feedback. Nothing fades, slides, or reveals on scroll. A landing section below the fold, or a news list item, appears exactly as it will sit — instantly, at rest.

04

Signal is earned; Brass is the brand. Green only marks an actual positive number or a verified badge. Gold marks CHOSN itself — wordmark, dividers, SKU tags — and carries no meaning about price.

/* Engineer handoff — CSS-only, no JS required */
.ticker-track {
  display: flex; width: max-content;
  animation: ticker-scroll 26s linear infinite;
}
.ticker-shell:hover .ticker-track { animation-play-state: paused; }

@keyframes ticker-scroll {
  from { transform: translateX(0); }
  to   { transform: translateX(-50%); }  /* track = content ×2, seamless wrap */
}

@media (prefers-reduced-motion: reduce) {
  .ticker-track { animation: none; transform: none; }
  .ticker-track .tick:nth-child(n+7) { display: none; }  /* static top movers only */
}

Trigger: page load, runs continuously. Pause: hover (direct feedback, allowed). Reduced motion: no transform at all — same real rows, first six, static. Nothing else on the landing page animates without a user action.

Section 06

Pass 2 — self-critique

What Pass 1 got checked against, and what actually moved.

Revised
Generic-if-logo-swapped?

Display face changed from Fraunces to Zilla Slab. Fraunces is currently one of the most common "distinctive serif" defaults regardless of configuration. Zilla Slab's stamped, certificate-like letterforms reference sneaker authentication tags and box labels directly — a reason grounded in CHOSN's own content, not just a different popular pick.

Pass
Motion scattered on scroll?

Held from Pass 1, tightened in writing: Principle 03 now explicitly states landing sections and news list items render at rest with no entrance animation — closing the loophole where "just the hero" quietly grows into fade-ups everywhere else.

Pass
One radius/shadow language?

Zero radius, hairline border, no shadow, no exceptions — including chips and buttons, which is where most systems quietly cave and round "just this once." Confirmed with no revision needed.

Revised
Does price data read as hero content?

data-hero bumped from 40px to 44px — larger than display-section (36px). In Pass 1 the price figure was sized close to a section headline; now it's larger than the section headline sitting right next to it on the comparison page, which is the actual test of "hero content."
